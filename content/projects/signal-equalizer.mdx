## Overview

This project turns signal processing from a collection of offline calculations into an interactive visual instrument. Users can load audio or biomedical data, adjust frequency bands, and immediately compare the original and reconstructed signals in both the time and frequency domains.

<ProjectGallery />

## Features

- Four domain-aware modes for uniform signals, musical instruments, animal sounds, and ECG recordings.
- Rectangle, Hamming, Hanning, and Gaussian frequency windows for comparing smoothing behavior.
- Linked input and output viewers with playback, speed, zoom, pan, and reset controls.
- Live spectrograms that expose how slider changes affect frequency content—not only waveform shape.
- CSV, WAV, and MP3 ingestion plus reusable custom signal configurations.
- Synchronized audio playback for direct before-and-after evaluation.

## Architecture

The PyQt controller coordinates a signal model, equalization calculations, graph playback, audio output, and spectrogram rendering. Domain-specific band definitions sit above the numerical layer, allowing the same processing pipeline to behave as a general equalizer, an instrument isolator, or an ECG analysis aid. NumPy and SciPy handle the transforms while PyQtGraph and Matplotlib keep the interface responsive and analytically useful.

## Challenges

The difficult part was maintaining one source of truth across several representations of the same signal. Playback position, waveform cursors, transformed output, and spectrograms all had to remain synchronized while users changed frequency gains or playback speed. Window selection added another engineering tradeoff: sharp boundaries offer precise control but introduce different artifacts from smoother windows.

## Lessons learned

Building the same interaction around music, animal sounds, and ECG recordings made the shared mathematics—and the limits of a one-size-fits-all interface—much clearer. I learned to treat scientific visualization as part of the product rather than an afterthought: the paired plots explain the result, reveal mistakes quickly, and help users form intuition about frequency-domain processing.
