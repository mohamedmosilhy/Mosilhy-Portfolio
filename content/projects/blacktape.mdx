## Overview

The Blacktape website presents a digital infrastructure brand through an animated introduction, service and client sections, device mockups, and a contact path. The implementation is a responsive React single-page application deployed on Vercel.

<ProjectGallery />

## Features

- An SVG introduction coordinated with critical asset prefetching.
- A hero sequence built from local image frames.
- Responsive navigation with active-section detection.
- Pinned, horizontal, and vertical scroll sequences.
- Device mockups, content modals, phone slides, and client-side contact validation.
- Switchable local and CDN asset sources.

## Architecture

The Vite application is organized around page-section and interaction components. Shared constants centralize content, asset paths, and animation configuration. GSAP contexts and ScrollTrigger coordinate animation lifecycles, while responsive layouts choose mobile or desktop choreography.
