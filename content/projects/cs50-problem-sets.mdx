## Overview

CS50 was the start of my programming journey. These problem sets document the point where coding stopped being isolated syntax and became a way to reason about memory, performance, data, and systems. The repository moves from small C programs into image and file processing, hash tables, Python, relational investigations, and complete web workflows.

<ProjectGallery />

## Features

- **Speller:** implemented dictionary lookup with a hash table and worked directly with allocation, pointers, and cleanup.
- **Recover:** reconstructed JPEG files from raw memory-card data by recognizing binary signatures and managing file boundaries.
- **Filter:** manipulated bitmap pixels to implement image transformations while respecting low-level image layout.
- **Fiftyville:** solved a narrative investigation by composing SQL queries across related tables and following evidence step by step.
- **Finance:** connected Flask routes, authentication, SQLite data, and external quote workflows in a server-rendered stock simulator.

## Architecture

The value of this collection is the progression between exercises. C made memory and cost visible; Python let me express the same problem-solving ideas at a higher level; SQL introduced declarative reasoning across relationships; and the web assignments combined those foundations into stateful applications. Each problem had a narrow brief, but the solutions required debugging assumptions rather than only filling in syntax.

## Challenges

The most instructive work happened at boundaries: interpreting bytes correctly, avoiding memory leaks, choosing a data structure that fit the access pattern, and turning a question into a sequence of relational queries. Those constraints taught me to inspect what a program is actually doing instead of relying on what I intended it to do.

## Lessons learned

CS50 established the habits that still shape my work: decompose a problem, understand the data representation, test edge cases, and explain the tradeoff behind a solution. It gave me the confidence to continue through The Odin Project, the MERN stack, freelance work, and more specialized scientific and machine-learning projects.
