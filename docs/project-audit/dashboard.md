# Dashboard

## Overview

A nine-page static dashboard demonstrating a consistent responsive administration interface.

## Purpose

It showcases multi-page HTML/CSS layout work for account, project, course, file, and settings views.

## Main Features

- Shared sidebar and header across nine pages
- Cards, tables, badges, progress indicators, settings, and profile views
- Responsive desktop and mobile layouts

## Technology Stack

- Frontend: HTML5, CSS3, CSS Grid, Flexbox
- Backend/Database/Authentication/Storage: Not applicable
- Deployment: GitHub Pages
- Libraries: Font Awesome

## Architecture

Independent static pages share a visual system but not a component runtime.

## Folder Structure

Multiple root HTML files represent routes; shared CSS and image assets provide presentation.

## Database

Not applicable.

## API

Not applicable; controls and data are illustrative.

## Engineering Decisions

Reusable CSS utility classes and layout primitives keep visual consistency across otherwise duplicated HTML pages.

## Technologies Used

HTML, CSS, CSS Grid, Flexbox, Font Awesome.

## Potential Portfolio Highlights

Broad interface coverage, responsive information density, and consistent styling.

## Missing Pieces
