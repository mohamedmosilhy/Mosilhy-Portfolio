# Framing Memories

## Overview

An interactive photographer portfolio with configurable accent themes, rotating imagery, gallery modals, and persisted preferences.

## Purpose

It presents photographic work and services while demonstrating richer vanilla JavaScript interactions.

## Main Features

- Accent theme and hero-background controls
- Preferences persisted in `localStorage`
- Timed random hero backgrounds
- Gallery-generated image modal
- Skills animation, timeline, testimonials, and mobile navigation

## Technology Stack

- Frontend: HTML, CSS, JavaScript
- Backend/Database/Authentication: Not applicable
- Storage: Browser `localStorage` and local assets
- Deployment: GitHub Pages
- Libraries: None central to the implementation

## Architecture

A static document enhanced by a single interaction layer that manages settings, scrolling, navigation, and gallery behavior.

## Folder Structure

HTML and CSS define sections; JavaScript controls runtime behavior; image directories hold gallery and background assets.

## Database

Not applicable.

## API

Not applicable; the contact presentation has no server submission.

## Engineering Decisions

User preferences survive reloads, gallery items generate modal behavior from document data, and scroll position triggers skill animations.

## Technologies Used

HTML, CSS, JavaScript, localStorage.

## Potential Portfolio Highlights

Persistent customization, gallery interaction, and feature-rich vanilla JavaScript.

## Missing Pieces
