# Restaurant Page

## Overview

A three-view restaurant website whose page content is generated by vanilla JavaScript modules.

## Purpose

It demonstrates modular DOM rendering and bundled front-end assets for a restaurant presentation.

## Main Features

- Home, menu, and contact views
- Persistent navigation
- Six menu dishes with imagery
- Responsive styling

## Technology Stack

- Frontend: JavaScript ES modules, HTML, CSS
- Backend/Database/Authentication/Storage: Not applicable
- Deployment: GitHub Pages
- Libraries: Webpack and HtmlWebpackPlugin

## Architecture

Each view is a module that creates its DOM subtree; the entry module switches content while preserving the shell.

## Folder Structure

`src` contains page modules, styles, and the entry point; Webpack configuration controls bundling and HTML generation.

## Database

Not applicable.

## API

Not applicable.

## Engineering Decisions

The interface avoids duplicated HTML by generating each page through reusable JavaScript modules.

## Technologies Used

JavaScript, HTML, CSS, Webpack.

## Potential Portfolio Highlights

Modular DOM construction and clean single-page navigation without a framework.
