# Calculator Webpage

## Overview

A browser calculator supporting common arithmetic and several unary operations.

## Purpose

It provides a compact JavaScript exercise in input handling and expression evaluation.

## Main Features

- Addition, subtraction, multiplication, division, and percentages
- Decimals, parentheses, square, and square root
- Clear and delete controls

## Technology Stack

- Frontend: HTML, CSS, JavaScript
- Backend/Database/Authentication/Storage: Not applicable
- Deployment: GitHub Pages
- Libraries: None

## Architecture

A static interface delegates button input and display updates to a single client-side script.

## Folder Structure

The repository contains one page, one stylesheet, and JavaScript logic.

## Database

Not applicable.

## API

Not applicable.

## Engineering Decisions

Display symbols are translated into JavaScript operators before evaluation. The implementation uses `eval`, explicitly as a learning simplification.

## Technologies Used

HTML, CSS, JavaScript.

## Potential Portfolio Highlights

Compact interaction logic and a clear CSS Grid keypad.

## Missing Pieces

Replace `eval` with a parser, add keyboard input, robust error handling, accessibility semantics, and unit tests.
