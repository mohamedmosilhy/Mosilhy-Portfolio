# Homepage

## Overview

An earlier static personal portfolio featuring a profile introduction, project gallery, and contact details.

## Purpose

It provides a simple public landing page for a developer’s work and contact channels.

## Main Features

- Profile hero
- Nine GitHub project cards
- Contact, location, phone, email, GitHub, and LinkedIn information
- Responsive layout

## Technology Stack

- Frontend: HTML, CSS
- Backend/Database/Authentication/Storage: Not applicable
- Deployment: GitHub Pages
- Libraries: Font Awesome, Google Fonts

## Architecture

A single static document with section-based CSS.

## Folder Structure

Root HTML and CSS files are accompanied by profile and project imagery.

## Database

Not applicable.

Not applicable.

## Engineering Decisions

## Technologies Used
