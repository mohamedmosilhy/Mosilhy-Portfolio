# Kasper Template

## Overview

A long-form static agency template recreated with HTML and CSS.

## Purpose

It demonstrates responsive layout, layered section styling, and fidelity to a supplied design.

## Main Features

- Hero, services, design, portfolio, video, statistics, and pricing sections
- Testimonials, skills, contact form, and footer
- Responsive layouts and decorative states

## Technology Stack

- Frontend: HTML, CSS
- Backend/Database/Authentication/Storage: Not applicable
- Deployment: GitHub Pages
- Libraries: Normalize.css, Font Awesome, Google Fonts

## Architecture

A single static page organized into semantic marketing sections and shared CSS patterns.

## Folder Structure

Root markup references shared styles and categorized image assets.

## Database

Not applicable.

## API

Not applicable; form and filtering controls are presentational.

## Engineering Decisions

Media queries, reusable containers, pseudo-elements, and CSS overlays create responsive visual effects without JavaScript.

## Technologies Used

HTML, CSS, Normalize.css, Font Awesome.
