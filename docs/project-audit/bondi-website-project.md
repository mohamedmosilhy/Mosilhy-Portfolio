# Bondi Website Project

## Overview

A responsive, single-page agency template implemented with Bootstrap and custom CSS.

## Purpose

It demonstrates recreation of a multi-section marketing design for front-end learning.

## Main Features

- Sticky collapsible navigation, hero, services, portfolio, team, and blog
- Partner, newsletter, pricing-style, and footer content
- Responsive Bootstrap layout

## Technology Stack

- Frontend: HTML5, CSS3, Bootstrap
- Backend/Database/Authentication/Storage: Not applicable
- Deployment: GitHub Pages
- Libraries: Bootstrap, Font Awesome, Google Fonts

## Architecture

A static page assembled from Bootstrap layout primitives and project-specific styling.

## Folder Structure

The root HTML document references CSS and organized image/font assets.

## Database

Not applicable.

## API

Not applicable; search, filters, login, and newsletter controls are presentational.

## Engineering Decisions

Bootstrap provides responsive grids and navigation behavior while custom CSS establishes the visual theme.

## Technologies Used

HTML, CSS, Bootstrap, Font Awesome.

## Potential Portfolio Highlights

Responsive section composition and consistent visual theming.

## Missing Pieces
