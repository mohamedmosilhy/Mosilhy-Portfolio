# Leon Template

## Overview

A responsive static agency template built from a supplied design.

## Purpose

It demonstrates foundational HTML/CSS skills and reusable marketing-page patterns.

## Main Features

- Hover navigation menu
- Hero, features, services, portfolio, about, and contact sections
- Responsive container system

## Technology Stack

- Frontend: HTML, CSS
- Backend/Database/Authentication/Storage: Not applicable
- Deployment: GitHub Pages
- Libraries: Normalize.css, Font Awesome

## Architecture

A single static page with shared container and heading classes.

## Folder Structure

Root markup and styles reference local images and webfont/icon dependencies.

## Database

Not applicable.

## API

Not applicable.

## Engineering Decisions

Reusable container widths and special-heading styles standardize sections; media queries control layout breakpoints.

## Technologies Used

HTML, CSS, Normalize.css, Font Awesome.
