# CS50 Problem Sets

## Overview

A consolidated repository of solutions across CS50’s C, Python, SQL, web, and Flask coursework.

## Purpose

It records practice in foundational algorithms, memory, data structures, databases, and web development.

## Main Features

- C fundamentals, pointers, memory, and file I/O
- Search/sort and image/audio processing exercises
- Python translations and data-processing tasks
- SQL investigations and relational queries
- Flask applications including the Finance stock simulator
- Notable exercises such as Speller, Recover, Filter, and Fiftyville

## Technology Stack

- Frontend: HTML, CSS, JavaScript in web exercises
- Backend: C, Python, Flask
- Database: SQLite/SQL exercises
- Authentication: Exercise-specific where implemented
- Storage: Local files and SQLite
- Deployment: No deployment found
- Libraries: Course-specific standard dependencies

## Architecture

This is an aggregate coursework repository. Each problem set is independent and follows the structure required by its assignment.

## Folder Structure

Directories are organized by week/problem and contain solution source, provided assets, and exercise-specific files.

## Database

SQL exercises and Flask projects use assignment-specific schemas; there is no shared data model.

## API

Only exercise-specific Flask routes exist; there is no repository-wide API.

## Engineering Decisions

Implementations include hash-table dictionary lookup, bitmap processing, file recovery, relational investigation, and server-rendered stock workflows.

## Technologies Used

C, Python, SQL, SQLite, Flask, HTML, CSS, JavaScript.
