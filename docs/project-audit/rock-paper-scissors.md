# Rock Paper Scissors

## Overview

A browser implementation of Rock Paper Scissors with computer choices and score tracking.

## Purpose

It is a small JavaScript exercise in event handling, branching game rules, and UI feedback.

## Main Features

- Player choice controls
- Random computer choice
- Round result feedback
- Running score

## Technology Stack

- Frontend: HTML, CSS, JavaScript
- Backend/Database/Authentication/Storage: Not applicable
- Deployment: GitHub Pages
- Libraries: None

## Architecture

A static interface delegates choice events and score updates to client-side functions.

## Folder Structure

The root contains the HTML page, stylesheet, script, and visual assets.

## Database

Not applicable.

## API

Not applicable.

## Engineering Decisions

Computer moves are selected randomly and each round immediately maps the choice pair to a result.

## Technologies Used

HTML, CSS, JavaScript.
