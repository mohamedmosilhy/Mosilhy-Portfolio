# Mosilhy Store Landing Page

## Overview

A static product marketing page centered on premium consumer electronics.

## Purpose

It demonstrates visual hierarchy and responsive e-commerce landing-page layout.

- Header, hero, signup call to action, and product showcase
- iPhone, MacBook, and watch content
- Quote, final call to action, and footer
